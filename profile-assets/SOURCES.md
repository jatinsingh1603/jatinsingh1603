## Navigation marks

- `linkedin-official.svg` embeds the unmodified official blue `LI-In-Bug.png`
  from LinkedIn's current [in] Logo download pack, retrieved on 2026-10-07:
  https://content.linkedin.com/content/dam/me/business/en-us/amp/xbu/linkedin-revised-brand-guidelines/logos/in-logo.zip
- Official source page: https://brand.linkedin.com/downloads
- Usage guidance: https://brand.linkedin.com/in-logo. The [in] Logo is permitted
  as a hyperlink to a member's LinkedIn profile. The profile link artwork keeps
  the original logo's colours, registered mark, proportions and surrounding
  space. The supplied PNG bytes are embedded intact in a self-contained SVG
  wrapper; this is not a traced or redrawn vendor mark.
- `link-portfolio.svg` uses the exact original portfolio BrandMark geometry and
  palette from `portfolio/components/brand-mark.tsx`.
- Résumé and contact navigation use original document and envelope interface
  icons. Regenerate all four navigation assets with `render_link_art.py`.
